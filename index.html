To make dashboards fully interactive on this site (optional)

  1. Open your PBIX in Power BI Desktop and choose Publish to your Power BI workspace (requires a Power BI account).
  2. In Power BI Service, open the report > File > Embed > Publish to web (note: Publish to web makes it public). For secure embedding use Power BI Embedded or a secure link — see Microsoft docs.
  3. Copy the embed <iframe> code and paste it in place of the PDF iframe in index.html. Example provided in README inside the ZIP.

If you want, I can help craft the exact iframe embed code once you publish the reports to Power BI Service (I can't publish them for you).
