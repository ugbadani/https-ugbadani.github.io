Personal website package for Daniel Chuks Ugbajah
=================================================

Files:
- index.html
- style.css
- script.js
- assets/ (contains PDFs and PBIX files)

How to preview locally:
1. Unzip the package.
2. Open index.html in your browser.

How to host on GitHub Pages:
1. Create a new repository named 'ugbadani.github.io' (or any name).
2. Upload the contents of this folder to the repository root.
3. In repository Settings -> Pages -> choose branch 'main' (or 'master') and root folder. Save.
4. After a minute the site will be live at https://ugbadani.github.io (if you used that repository name).

Note about interactive Power BI:
- To embed interactive Power BI reports you must publish your PBIX files to Power BI Service (requires an account).
- Use the embed iframe code from Power BI Service and replace the PDF iframe in the Projects section with the Power BI iframe.
- For secure embedding in a production site consult Power BI Embedded or Azure services.
